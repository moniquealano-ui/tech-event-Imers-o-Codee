 Imersão Code
O Imersão Code é um projeto de um site sobre um evento de tecnologia, desenvolvido em grupo para colocar em prática o que aprendemos sobre HTML e CSS.
O site tem como tema principal a Inteligência Artificial e apresenta informações sobre o evento, palestras, workshops e outros detalhes importantes.
No início do site, temos o título Inteligência Artificial e a frase “O futuro da tecnologia começa aqui”, que apresenta o tema principal para quem acessa a página.
O site também possui uma parte sobre o evento, onde falamos um pouco sobre tecnologia, programação e Inteligência Artificial.
Na parte das palestras, apresentamos três temas: Inteligência Artificial, O futuro da tecnologia e Programação e inovação. Cada palestra tem uma descrição e o nome de um palestrante.
Também temos uma seção de workshops, com atividades sobre Inteligência Artificial, criação de sites e programação, mostrando alguns assuntos que podem ser aprendidos durante o evento.
Outra parte do site apresenta as informações do evento, como data, horário, inscrição gratuita e formato. Também incluímos a localização, com o endereço informado para a realização do evento.
Na seção de patrocinadores, aparecem os nomes Google, Microsoft, OpenAI e NVIDIA. No final da página, temos o rodapé com informações de contato, telefone, WhatsApp e uma breve descrição do Imersão Code.
Para desenvolver o site, utilizamos HTML para organizar os conteúdos e criar a estrutura da página, e CSS para definir as cores, os fundos, os tamanhos dos textos e a aparência dos cards.
O projeto foi feito em grupo, com cada integrante responsável por uma parte do site. Depois, juntamos as partes para formar uma única página. Com esse trabalho, conseguimos praticar o que aprendemos e conhecer melhor como funciona o desenvolvimento de um site.
